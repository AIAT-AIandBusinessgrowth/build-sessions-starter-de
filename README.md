# Build Sessions Starter

**Deutsch** · [English](https://github.com/AIAT-AIandBusinessgrowth/build-sessions-starter) · [Hrvatski](https://github.com/AIAT-AIandBusinessgrowth/build-sessions-starter-hr)

Dein erstes Werkzeug mit einem AI Agent, also einer KI, die Aufgaben selbst ausführt, an einem Tag. Du musst nicht programmieren können.

Vor dem Workshop: Die Setup-Anleitung bekommst du mit der Einladung zu deinem Termin. Jede Sprache hat eine eigene Fassung des Starters, wähle oben die passende aus.

## Drei Schritte

1. **Eigene Kopie holen.** Melde dich auf GitHub an und klicke auf **Use this template → Create a new repository**. Ein Repository ist ein Projektordner mit gespeicherten Versionen. Wähle **Private** und erstelle es. Öffne dann **Code → Open with GitHub Desktop** und klone es, also kopiere es auf deinen Computer. Ohne GitHub-Konto: **Code → Download ZIP** wählen und die ZIP-Datei entpacken.
2. **Ordner öffnen.** Wähle in Cursor **File → Open Folder** und öffne deinen Ordner. Öffne dann den Agent-Chat. In Claude Code oder Codex öffnest du ebenso den Ordner in der App oder startest im Terminal, der Eingabe für Befehle, `claude` oder `codex` in diesem Ordner.
3. **`start` tippen.**

Der Agent lernt dich kennen, hilft dir bei der Ideenfindung, plant mit dir, baut eine erste Version und prüft sie. Du entscheidest, er macht die Arbeit.

Wenn dein Ordner ein Git-Repository ist, sagt dir der Agent, wann du eine Version speichern kannst: In Cursor (oder VS Code) links **Quellcodeverwaltung** öffnen, eine kurze Nachricht eintippen, **Commit**, dann **Sync** bzw. **Push**. Oder in GitHub Desktop eine kurze Nachricht eintippen, **Commit to main**, dann **Push origin**. Ein Commit speichert eine Version zum Zurückkehren, ein Push überträgt sie in dein privates Repository auf GitHub.

## Wörter, die du jederzeit nutzen kannst

`weiter` (next) · `zurück` (back) · `erklär` (explain) · `prüfen` (check) · `wo sind wir` (where are we)

## Was hier drin ist

| Datei oder Ordner | Was das ist |
|---|---|
| `AGENTS.md` | Wie der Agent dich begleitet. Cursor liest die Datei automatisch. Claude Code liest sie über `CLAUDE.md`. |
| `me.md` | Was der Agent über dich weiß. Er füllt die Datei aus. |
| `rules/` | Drei Regeln für den Agent: nur erfundene Daten, fertig heißt geprüft, kleine Schritte. |
| `projects/` | Ein Ordner pro Idee, mit deinem Plan und deinem Werkzeug. |
| `notes/learned.md` | Zwei Sätze nach jedem Schritt: was du gemacht hast und was du dir merken solltest. |
| `examples/ana/` | Ein fertiges Beispiel mit erfundenen Daten. Sag „Probiere das Beispiel Ana aus“. |

## Regel eins

Nur erfundene Daten. Keine echten Namen, Kundendaten, Dateien aus der Arbeit, Passwörter oder Schlüssel. Persönliche AI-Abos haben keinen Vertrag zur Auftragsverarbeitung mit deiner Organisation. Das gilt auch für dein privates Repository.

## Weitermachen

Derselbe Ordner, derselbe Plan. Öffne den Agent wieder und sag `wo sind wir`. Wenn du Versionen in deinem privaten Repository gespeichert hast, findest du sie dort wieder. Weitere Übungen: [AI:AT Build Sessions](https://github.com/AIAT-AIandBusinessgrowth/aiat-build-sessions).
